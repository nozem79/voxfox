# Tile pictograms

One SVG per ready-made tile of Type and speak. The file name is the Dutch
word of the tile (`dorst.svg`, `ik-heb-dorst.svg`, `vraagteken.svg` for "?").
The English, German, French and Spanish boards use the same pictures; the
words per language are in `src/voxfox_core/typespeak.py` (`_ICONS`).
